Controle de conta bancaria

A ideia é praticar o uso de variáves, entrada e saída de dados, estruturas de decisão e repetição em Java, bem como aplicar esses conceitos.

A aplicação tem uma entrada fixa de dados de um usuário de um sistema bancario, qual pode ser efetuado a consulta do saldo, receber e fazer uma transferência e encerrar a aplicação.
